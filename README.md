# ❤️ Valentine Week Web Experience

An interactive, responsive, romantic web experience celebrating each day of Valentine's Week with dynamic animations, audio/visual reveals, and personalized pages.

---

## 📅 Days of Valentine's Week

The project features a dedicated page for every day of the week, with date-aware unlocking logic in `script.js`:

| Date | Day | Page | Highlights |
| :--- | :--- | :--- | :--- |
| **Feb 7** | 🌹 **Rose Day** | `rose-1.html` | Animated rose video showcase & heartfelt message |
| **Feb 8** | 💍 **Propose Day** | `propose-1.html` | Interactive proposal reveal & background melodies |
| **Feb 9** | 🍫 **Chocolate Day** | `chocolate-1.html` | Sweet themed cards & animations |
| **Feb 10** | 🧸 **Teddy Day** | `teddy-1.html` | Soft aesthetics & interactive teddy elements |
| **Feb 11** | 🤝 **Promise Day** | `promise-1.html` | Meaningful promises list & reveal blocks |
| **Feb 12** | 🫂 **Hug Day** | `hug-1.html` | Warm hugs, quotes & memory slider |
| **Feb 13** | 💋 **Kiss Day** | `kiss-1.html` | Romantic card reveals & interactions |
| **Feb 14** | 💖 **Valentine's Day** | `valentine-1.html` | Grand celebration with interactive fireworks & audio |

---

## ✨ Features

- **Modern Glassmorphic UI**: Built with elegant typography (Dancing Script, Playfair Display, Poppins), subtle gradients, and glassmorphism styling.
- **Date-based Unlock Mechanism**: Automatically detects the current date in February and unlocks the corresponding day page.
- **Audio & Video Integration**: Responsive background music player and device-optimized video loops (PC and mobile versions).
- **Responsive Layout**: Designed to look beautiful across desktops, tablets, and smartphones.
- **Interactive Micro-animations**: Confetti/fireworks canvas, memory slider, card flip animations, and WhatsApp message trigger.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic document structure
- **CSS3**: Vanilla CSS styling, flexbox/grid layouts, keyframe animations, glassmorphism
- **JavaScript (ES6+)**: Interactive logic, date mapping, HTML5 Canvas fireworks, audio controls

## 🚀 Getting Started

### Local Setup
1. Clone the repository:
   ```bash
   git clone git@github.com:Frenil0393/velentine-week.git
   cd velentine-week
   ```

2. Open `index.html` in your browser:
   - Double-click `index.html`, or
   - Use a local dev server such as Live Server in VS Code, or:
     ```bash
     npx serve .
     ```

> **Note**: Image files are excluded via `.gitignore`. If you'd like to personalize the site, add your own images (`photo.jpeg`, `image (1).jpeg` to `image (6).jpeg`) into the project root.
